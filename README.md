# 오공해봄 업무 도우미

첫 화면에서 다음 앱을 열 수 있습니다.

- 주문서 만들기: `quote/`
- 고객 문의 답장 도우미: `reply/`
- AI 상품 설명 생성기: `copy/`

팀 코드는 각 앱의 설정에서 입력합니다. 코드 파일이나 GitHub에 적지 않습니다.
브라우저에 보관된 주문·문의·문구·팀 코드는 사이트 파일과 함께 배포되지 않습니다.

## 변경한 내용 공개하기

`main`에 변경을 올리면 GitHub Pages가 새 버전을 공개합니다.
이 컴퓨터의 저장소에는 커밋 후 자동 업로드를 연결할 수 있는 `.githooks/post-commit`이 들어 있습니다.
다른 컴퓨터에서 이 기능을 사용하려면 해당 저장소에서 `git config core.hooksPath .githooks`를 한 번 실행합니다.
인터넷 연결이나 로그인 문제로 업로드가 안 되더라도 커밋은 내 컴퓨터에 남습니다.
